# Published release builds

This folder records the published alpha releases. To reproduce alpha.2, check out
`v0.1.0-alpha.2` and follow the build instructions at that tag. Its source archive,
binary artifacts and blueprint ZIP are unchanged.

The main branch now contains the Exploration Hut development snapshot. Follow
[development build instructions](../DEVELOPMENT.md) and use `supplyDevJar`.
Addon code remains GPL-3.0-only; Arcology assets retain their separate permission
and attribution terms. Preserve LICENSE, NOTICE and the template/Gradle notices.
