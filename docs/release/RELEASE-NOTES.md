# Colony Horizons 0.1.0-alpha.1

First public alpha of the MineColonies compatibility addon, with the separately installed Arcology Horizons pack.

Includes lantern support-removal safety, Nether worker resumption, stored enchantment handling, plantation shears, animal-home reload and quarry compatibility fixes. The separate pack contains 305 blueprints, including repaired designs and new Stable, Gatehouse, quarry and plantation modules.

Install the JAR in `mods`. Extract the blueprint ZIP into `blueprints`, producing `blueprints/arcology-horizons/pack.json`. See INSTALLATION.md for exact required mods. Neither dependencies nor the style pack are bundled in the JAR.

Original Arcology by BlockyUniverseProductions: https://www.planetminecraft.com/mod/arcology-5819547/ . Unofficial adaptation published with permission. Code is GPL-3.0-only; Arcology assets are separately permitted, not GPL. Matching source and checksums are included.

Verified: official launcher world/preview/save/reload smoke test, byte-identical source rebuild, artifact checks and 95 pack contracts. Multiplayer remains unverified. Automated outposts, Mayor UI and protected deliveries are not available yet.
